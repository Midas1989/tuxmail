# TuxMail Branding

| File | Purpose |
|---|---|
| `tuxmail-logo.png` / `.webp` | Full logo with wordmark (1024×1024) – README, website, login/onboarding |
| `tuxmail-penguin.png` | Penguin only, transparent background – source for all icons |
| `icons/icon-<size>.png` | App icons 16–1024 px (rounded square, light background) |
| `icons/icon-maskable-192/512.png` | PWA maskable icons (content inside the 80 % safe zone) |
| `icons/apple-touch-icon-180.png` | iOS home screen icon |
| `icons/favicon.ico` | Browser favicon (16–256 px) |
| `icons/tuxmail.ico` | Windows executable icon |

Brand colors (taken from the logo): navy `#1c2b45` (wordmark, primary), orange `#f59e0b` (accent), light background `#f3f6fa`.
